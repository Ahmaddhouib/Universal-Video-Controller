# About Universal Video Controller
Universal Video Controller is completely free and unlimited.

Universal Video Controller started as a personal passion project built out of a simple desire to make watching videos online a better experience. As a solo developer, I created this extension to solve the everyday frustrations I was running into myself—and I’m excited to share it with anyone else looking for smoother, more intuitive control over their web videos.
---

### What it actually does

- **Speed controls that feel good:** Tap to bump speed by custom steps, jump straight to your favorite speed, or hold a key / mouse button for a temporary boost with a clean on-screen HUD.
- **Shorts auto-scroll:** When a YouTube Short or Reel finishes, it automatically scrolls straight to the next one.
- **Volume & Audio boost:** Boost quiet videos past 100%, adjust volume in steps, or toggle mute with a tap.
- **Per-site memory:** Set a podcast site to 1.8x and YouTube to 1.25x—it remembers your volume and speed per site automatically.
- **Frame-by-frame seeking:** Step backward and forward frame by frame with high precision.

---

### Privacy & Transparency (Why this repo exists)

This repository is public so anyone can inspect the code:
- **Zero tracking or analytics.** No telemetry, no background pings, no external servers.
- **Zero remote scripts.** Every stylesheet, theme, and script is bundled right here locally.
- All your custom hotkeys and preferences stay in your browser's local storage.

### How to load it unpacked

You can grab it directly from the [Chrome Web Store](https://chromewebstore.google.com/detail/universal-video-controlle/dmepibiilnbbpgchbjdfegbibklhmgdi) or [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/universal-video-controller-ff/), or run the code directly:

**Chrome / Brave / Edge:**
1. Download or clone this folder.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this folder.

**Firefox:**
1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on...**
3. Select the `manifest.json` file in this folder.
